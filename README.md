# AI Security Alert Triage Assistant

A Python-based cybersecurity tool that uses AI to assist with the initial triage of security alerts.

## Project Goals

The project will analyze security alerts and provide:

- Preliminary severity assessment
- Explanation of why an alert may be suspicious
- Recommend investigation steps
- MITRE ATT&CK technique mapping
- Structured security reports

## Technologies

- Python
- AI/LLM API
- JSON
- Git/Github
- Pytest
